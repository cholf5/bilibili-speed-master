# Keyboard Shortcuts

This extension follows YouTube-style shortcuts on video pages.

## Full Shortcut List
| Keyboard shortcut | Function |
| --- | --- |
| Spacebar | Play/Pause when the seek bar is selected. Activate a button if a button has focus. |
| Play/Pause Media Key | Play / Pause. |
| `k` | Pause/Play in player. |
| `m` | Mute/unmute the video. |
| Stop Media Key | Stop. |
| Next Track Media Key | Moves to the next track in a playlist. |
| Left/Right arrow on the seek bar | Seek backward/forward 5 seconds. |
| `j` | Seek backward 10 seconds in player. |
| `l` | Seek forward 10 seconds in player. |
| `Ctrl` + `→` (Windows) or `⌘` + `→` (Mac) | Go to the next chapter. |
| `Ctrl` + `←` (Windows) or `⌘` + `←` (Mac) | Go back to the previous chapter. |
| `.` | While the video is paused, skip to the next frame. |
| `,` | While the video is paused, go back to the previous frame. |
| `Shift` + `>` | Speed up the video playback rate. |
| `Shift` + `<` | Slow down the video playback rate. |
| Home/End on the seek bar | Seek to the beginning/last seconds of the video. |
| Up/Down arrow on the seek bar | Increase/Decrease volume 5%. |
| Numbers `1` to `9` | Seek to 10% to 90% of the video. |
| Number `0` | Seek to the beginning of the video. |
| `/` | Go to search box. |
| `f` | Toggle fullscreen (press again or Escape to exit). |
| `c` | Toggle captions/subtitles if available. |
| `Shift` + `N` | Move to the next video (playlist or suggested). |
| `Shift` + `P` | Move to the previous video (playlist only). |
| `i` | Open the Miniplayer. |

## Notes
- Shortcuts are ignored while typing in inputs, textareas, or editable fields.
- The extension actively applies the listed shortcuts where it can; some actions (next/previous, miniplayer, search focus) are best-effort and depend on page controls being present.
- Speed changes trigger the same per-channel persistence as player controls.
