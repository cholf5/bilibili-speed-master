这是一个浏览器插件：bilibili Speed Master

该插件的功能是：可以给B站的视频设置一个全局默认播放速度（比如1.5倍速）
然后可以给每个频道分别设置不同的速度。

需要拦截用户通过 video player 上的控件调整速度，也要拦截通过快捷键调整速度。
用户只要有任意调整速度的动作，就认为是对该频道设置速度了，哪怕最终调整完和全局速度一样。
用户调整某个频道任意一个视频的速度时，即对该频道所有视频生效。

## 开发技术栈

技术选型上使用 WXT + TypeScript + React + Tailwind CSS + Vite

## 界面说明
- 插件的 Popup 界面: ./docs/popup.md
- 插件的 Options 界面: ./docs/options.md

你可以使用 Chrome MCP 来调试插件效果和分析B站视频页面的行为，这是某视频的URL: https://www.bilibili.com/video/BV1AsiEB1E7Q

在B站 video player 右上角有一组调整视频速度的控件，从左往右分别是：
- 齿轮图标：点击后进入 Options 界面
- 减号按钮：每次点击降低 0.1 倍速
- 当前速度显示：显示当前视频的播放速度
- 加号按钮：每次点击提高 0.1 倍速

## 多语言支持
开发期间仅支持英语，但仍然需要有完善的国际化方案，方便后续添加其他语言支持。

## 特殊规则
B站有视频连播功能，当一个视频播放完毕后会自动播放下一个视频，这时需要确保下一个视频在播放时重新按规则设置好速度。

也就是说，B站是一个 SPA 应用，用户在浏览器地址栏看到的视频 URL 变化时，并不会导致页面刷新。
因此需要监听 URL 变化事件，在 URL 变化时重新应用速度设置规则.
